# TypeMaster v1.0.929 发行说明

> **发布日期**：2026-09-29
> **构建版本**：`1.0.0929.0838`
> **适用平台**：Windows 10 / 11（64 位）

本轮针对 **中老年人学五笔** 做专项优化。

---

## ✨ 重点更新

### 1. 长辈模式（一键预设）

给中老年学习者的一键开关，不用逐项去调：

| 自动应用 | 效果 |
| --- | --- |
| 字号放大 | 至少 26（正文更大） |
| 朗读语速放慢 | 慢 2 档 |
| 五笔逐码提示 | 自动打开 |
| 当前字大字显示 | 自动打开 |
| 语音朗读 | 自动打开 |
| 虚拟键盘 | 自动显示 |
| 主题 | 切换护眼绿（长时间看不累） |

关闭时**只恢复字号与语速**，其它设置保持你当前的选择。

### 2. 五笔逐码按键提示 —— 不会拆字根也能开始打

练习时屏幕直接显示：

```
明        JE        已打 0 码 / 共 2 码
编码 JE    第1码 J键（日）    第2码 E键（月）
```

五笔编码的每一位本身就对应一个键位，所以这是**确定可算**的提示，不是猜测。
配合键名（J 键=日），与字根口诀的记忆直接挂上钩。

**不用先背熟字根表，打开就能练。**

### 3. 当前字与编码大字显示

34px 大字显示当前要打的字与编码，不用眯眼找。

### 4. 练习时朗读当前字（自动放慢）

切到新字时朗读：

> 「明，编码 J E，第1码按J键，日，第2码按E键，月」

编码信息密度高，常规语速听不清，因此这里**固定比常规慢 2 档**。

### 5. 五笔入门课程支线（6 关）—— 不必先做完 20 关

新增独立支线，按**编码击键数**由少到多：

| 关卡 | 内容 |
| --- | --- |
| 1 | 一键成字（一级简码 25 字，一击成字） |
| 2 | 两码字 |
| 3 | 三码字 |
| 4 | 四码字 |
| 5 | 常用字综合 |
| 6 | 打一小段话 |

> **这是本轮最重要的一项。**
> 此前课程里五笔只有最后 1 关（毕业关），而解锁规则是"前一关已通关"——
> 等于要求你先完成 20 关英文指法 / 单词 / 句子练习才能开始学五笔。
> 现在五笔入门**独立解锁，第一关始终可玩**。

## 📚 五笔字库扩充：404 字 → 6489 字

此前字库只有 404 字，最常用 140 字只覆盖 **73.6%**，
缺「她 以 把 第 样 想 情 女 很 给 名 间 知 世 两 身 被 高 已 常 活」等字，
连一句完整的话都打不出来。

**现在**：

- 字表来源：**《通用规范汉字表》(2013) 一级字表(3500) + 二级字表(3000)**
  （三级字表 1605 字为专业领域生僻字，刻意不收录，避免练习时碰到「龘 / 甪」这类字）
- 编码来源：rime-wubi86 官方码表，取**最短可用编码**（含简码，与实际输入法击键一致）

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| 五笔字库 | 404 字 | **6489 字** |
| 最常用 140 字覆盖 | 73.6% | **100%** |
| 一级字表 3500 覆盖 | — | **100%** |

**原有 404 字的编码与顺序完全未改动**（逐一核对 0 差异），既有练习记录不受影响。

### 课程只出常用字

五笔入门支线**只从一级常用字（3500 字）中出题**。
初版实现按码长从全库随机抽，实测抽到「肼 / 棰 / 琏 / 哐 / 夼」这类生僻字，
对初学者是直接打击，已修正。

## 📦 安装与使用

1. 下载下方附件 `TypeMaster-v1.0.929-win-x64.zip`
2. 解压到任意目录（无需安装）
3. 双击 `TypeMaster.exe` 运行

**无需预先安装 .NET 运行时**——自包含单文件，原生库已一并打包。

### 给长辈的建议用法

1. 打开「系统设置」→ 勾选 **长辈模式**
2. 到「课程中心」，找到底部 **「五笔入门（零基础）」**，从第 1 关开始
3. 屏幕会逐码提示该按哪个键；不熟悉字根也能直接练
4. 想复习字根口诀，到「学习园地」点朗读按钮听

### 数据位置

`%LOCALAPPDATA%\TypeMaster\`（成绩 / 昵称 / 自定义文章 / 闯关进度）

**从旧版本升级不会丢失数据**：数据库采用非破坏性补列，历史成绩与设置完整保留。

## ⚠️ 已知限制

- **仅支持 Windows**（WPF + Windows 专有音频/语音 API）
- **发布包较大（175 MB）**——自包含单文件内含 .NET 运行时与原生库
- **逐码提示不做图形化字根拆解**（如「明 = 日+月」的形状拆解）。
  项目没有部件拆分库，从编码反推拆解会给出错误提示，因此只做**逐位按键指引**——
  这对"不知道下一个按哪个键"的核心困难是直接有效的
- **朗读需系统已安装中文语音引擎**（「设置 → 时间和语言 → 语音」可添加）；
  未安装时朗读自动跳过，不影响其它功能
- 五笔采用 **86 版编码**（与项目既有数据一致），非 98 / 新世纪版
