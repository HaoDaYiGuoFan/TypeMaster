# TypeMaster v1.0.1003 发行说明

> **发布日期**：2026-10-03
> **构建版本**：`1.0.1003.1005`
> **适用平台**：Windows 10 / 11（64 位）

本轮聚焦 **游戏乐园的游玩体验**：单词字号大幅放大、全面修复单词被遮挡的问题，
并修复一处窗口尺寸缺陷。同时包含自上一版 Release 以来的「入门难度档」等内容。

---

## ✨ 重点更新

### 1. 游戏单词字号大幅放大

游戏乐园对战过程中闪出的单词，字号从默认约 12px 累计放大到 **23px（+11px）**，
单词条区域同步加宽（130 → 230），最长 18 字母的长词（如 telecommunications）
也能单行完整显示。

游戏过程文字一并放大：得分 / 生命 / 连击数值 18px、输入框 14px、状态提示 15px，
小朋友看得更清楚。

### 2. 全面修复"单词被遮挡"

**根因**：界面上的单个游戏目标（卡通精灵 + 单词条）实际占位约 230×120，
而引擎一直按旧的 130~160 占位在计算出生点与越界判定——单词条伸出游戏区边缘时
被直接裁掉；字号放大后问题愈发明显。

**修复原则**：目标存活且可输入期间，**单词条必须完整落在游戏区内**。
六种模式逐一处理：

| 模式 | 修复内容 |
| --- | --- |
| 太空大战 | 横向生成范围收窄到完整占位内；落地线上移到"精灵触地"，单词不再在落地前逐渐沉入底边 |
| 打地鼠 | 地鼠与单词精确对准洞口正中；行位钳制，矮窗口下第二行单词不再被下边缘裁掉 |
| 抓小偷 | 横向生成与逃逸判定按完整占位计算；纵向活动带钳制，矮窗口下全程单词完整 |
| 青蛙吃虫 | 两侧入场对称（完全屏外入场）；按目标**中心**判定"到达青蛙"，虫子不再跑过青蛙才消失 |
| 打气球 | 横向生成范围收窄；改为在底部完整可见处出生——原来自屏幕下方整格升起时单词要约 8 秒才进入视野 |
| 生死时速 | "当前单词位"精确居中于赛道；矮窗口下纵向钳制 |

### 3. 修复：手动拉大的窗口被自动"居中还原"

此前在游戏中把窗口拖大后，过几秒窗口会自动回到屏幕中央并恢复原来的大小。

**根因**：拖大窗口时若边缘跨到另一块不同缩放比的显示器（或系统显示器设置变化），
窗口会重新执行启动时的尺寸适配——按配置里的旧尺寸重设并居中，手动调整被覆盖。

**现改为**：这些时机只在窗口超出屏幕时做收口修正，**不再重套配置尺寸、不再重新居中**，
手动调整的结果会被保留；启动时的自动适配行为不变。

### 4. 界面底色改为偏白不透明

界面底色由半透明深色调整为偏白不透明，整体更亮、对比更清晰。

### 5. 新增「入门」难度档（自 v1.0.930 起）

比简单档更易，面向刚接触键盘的小朋友：四档变为 **入门 / 简单 / 普通 / 困难**，
难度细分扩为 13 级；入门档单词更短、节奏更慢、生命更多。详见
[CHANGELOG.md](../CHANGELOG.md) 的 1.0.930 小节。

## 📦 安装与使用

1. 下载下方附件 `TypeMaster-v1.0.1003-win-x64.zip`
2. 解压到任意目录（无需安装）
3. 双击 `TypeMaster.exe` 运行

**无需预先安装 .NET 运行时**——自包含单文件，原生库已一并打包。

### 从旧版本升级

**直接覆盖 exe 即可**。使用者数据、成绩、闯关进度、自定义文章全部保留。

---

## ⚠️ 已知限制

- **仅支持 Windows**（WPF + Windows 专有音频/语音 API）
- **发布包较大（约 176 MB）**——自包含单文件内含 .NET 运行时与原生库
- **游戏区过矮时**（窗口被压得很扁）打地鼠上下两行会彼此靠近——建议游戏时保持窗口正常高度
- **朗读需系统已安装中文语音引擎**；未安装时自动跳过，不影响其它功能
