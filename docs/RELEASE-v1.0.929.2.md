# TypeMaster v1.0.929.2 发行说明

> **发布日期**：2026-09-29
> **构建版本**：`1.0.0929.0919`
> **适用平台**：Windows 10 / 11（64 位）

本轮实现 **多使用者切换** 与 **多分辨率 / DPI 适配**。

---

## ✨ 重点更新

### 1. 多使用者 —— 多人共用一台电脑，数据互不影响

典型场景：爷爷学五笔、奶奶学拼音，各练各的。

数据按使用者**物理分目录**存放：

```
%LOCALAPPDATA%\TypeMaster\
├─ users.json              使用者清单
└─ users\
   ├─ u1\                 使用者 1（成绩 / 昵称 / 闯关进度 / 自定义文章）
   └─ u2\                 使用者 2（与 u1 完全隔离）
```

**为什么用"分目录"而不是"加个用户标记"**：后者要给每张表加字段、
所有查询都带过滤条件，漏一处就会串数据；分目录天然不会串。

**使用方式**：

- **启动时**：有多个使用者会弹出选择窗口，双击名字即可进入
- **设置页 → 使用者**：切换 / 新建 / 重命名 / 删除

**行为说明**：

| 事项 | 行为 |
| --- | --- |
| 切换使用者 | **需要重启应用**。数据库连接在启动时就绑定了原目录，重启可确保不串数据 |
| 重命名 | 只改显示昵称，数据目录不动，**成绩不会"搬家"** |
| 删除使用者 | 需**两次确认**，会一并删除其全部数据且不可恢复 |
| 删除限制 | 不能删当前使用者，也不能删到只剩零位 |
| 从旧版升级 | 旧数据**自动迁移**到第一个使用者；迁移失败会弹窗告知并保留原文件 |

### 2. 多分辨率 / DPI 适配

支持 1080p ~ 4K、系统缩放 100% ~ 200% 的各种组合。

| 能力 | 说明 |
| --- | --- |
| Per-Monitor V2 DPI 感知 | 跨不同缩放比的显示器拖动时自动适配 |
| 启动自动适配 | 窗口按当前屏幕可用区自动选择尺寸 |
| 屏幕约束 | 无论设置多大，窗口始终完整落在屏幕内（含任务栏避让） |
| 实时重算 | 系统缩放变化、插拔外接显示器时自动重新适配 |
| 对话框约束 | 昵称 / 引导 / 导入文章 / 选择使用者窗口同样按工作区收口 |
| 虚拟键盘自适应 | 窄屏下整体等比缩小，不会横向溢出 |
| **界面缩放** | **0.8 ~ 1.6 倍手动调整**，独立于系统缩放 |

### 3. 按屏幕给的建议

| 你的情况 | 建议 |
| --- | --- |
| 2.8K / 3.2K / 4K，觉得字偏小 | 界面缩放 **1.15 ~ 1.30** |
| 1080p，系统缩放 150% 以上显拥挤 | 界面缩放 **0.85 ~ 0.95** |
| 1080p，系统缩放 175% / 200% | 已自动收窄；如仍拥挤可调小界面缩放 |
| 视力不佳 | 直接开**长辈模式**（字号、语速、提示一并调整） |

窗口尺寸滑块的**可调范围会按当前屏幕自动约束**，不会设出"屏幕放不下"的值；
也可以点「按当前屏幕重置尺寸」一键恢复。

## 🐞 本轮修复的三个真实缺陷

### 1. 窗口尺寸设置项完全无效（存在已久）

设置页有「窗口宽度」「窗口高度」两个滑块，但主窗口 `MainWindow.xaml` 里是硬编码的
`Width=1100 Height=840`，**从未读取这两个配置**——用户拖动滑块没有任何效果。

**现已真正生效。**

### 2. 低分屏高缩放时窗口超出屏幕

实测：**1080p 在 175% / 200% 缩放**下，屏幕工作区只剩约
1097×577 / 960×500 逻辑单位，而窗口最小尺寸固定 900×680，
**窗口必然溢出屏幕**（底部按钮点不到）。

> 值得注意：会把系统缩放调到 200% 的，往往正是视力不佳的用户——
> 而这类用户恰恰最需要这个软件可用。

**现已按工作区收窄，并在屏幕过小时临时放宽最小限制。**

### 3. 四个对话框在极端缩放下超出屏幕

昵称（460×430）、新手引导（620×580）、导入文章（580×500）、
选择使用者（520×520）——固定尺寸在 1080p @200% 下高度都会溢出。
现统一按工作区收口。

## 📦 安装与使用

1. 下载下方附件 `TypeMaster-v1.0.929.2-win-x64.zip`
2. 解压到任意目录（无需安装）
3. 双击 `TypeMaster.exe` 运行

**无需预先安装 .NET 运行时**——自包含单文件，原生库已一并打包。

### 从旧版本升级

**直接覆盖 exe 即可**。首次启动时旧数据会自动迁移到第一位使用者名下，
成绩、闯关进度、自定义文章、昵称都会保留。

---

## ⚠️ 已知限制

- **仅支持 Windows**（WPF + Windows 专有音频/语音 API）
- **发布包较大（175 MB）**——自包含单文件内含 .NET 运行时与原生库
- **切换使用者需重启应用**——技术原因见上文；这是有意设计，避免热切换导致数据串扰
- **成绩不跨 Windows 账户同步**——数据在 `%LOCALAPPDATA%` 下，换 Windows 登录账户需手动复制
- **朗读需系统已安装中文语音引擎**；未安装时自动跳过，不影响其它功能
