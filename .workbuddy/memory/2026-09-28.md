## TypeMaster 学习园地语音朗读（五笔字根口诀 + 拼音声韵母）

需求：学习园地中的五笔字根口诀与拼音声韵母需要能发声朗读。

### 技术选型（先实验后实现）
用 Windows 内置语音 `System.Speech`（SAPI），**离线、不联网、不产生任何网络请求**。
- 新增 NuGet：`System.Speech` 8.0.0（`TypeMaster.Services.csproj`）
- 本机可用中文语音：SAPI5 `Microsoft Huihui Desktop`(zh-CN)；OneCore 另有 3 个中文语音
- `SpeechService` 标注 `[SupportedOSPlatform("windows")]` 消除 CA1416 平台警告（否则新增 16 个警告）

### 关键实测结论（**用本机 ASR 反听验证，不是推测**）
这是本次开发最重要的收获，直接决定了数据设计：

1. **拼音绝不能直接交给语音引擎读拉丁字母**
   - `b p m f` → ASR 反听得到「BPMF」，即被读成英文字母名（bee/pee/em/eff）
   - 必须转成汉语拼音教学的「呼读音」汉字（b→玻、p→坡、m→摸、f→佛）
   - 整体认读音节同理：`zhi chi shi ri` → 被读成「G C R I」
   - **修复**：新增 `PinyinSpeech` 呼读音汉字表（声母 23 / 韵母 24 / 整体认读 16，已自检 100% 覆盖）

2. **口诀里括号内的读音提示会被一起读出来**
   - `王旁青头戋（兼）五一` → 读成「王庞青头尖，尖五一」
   - **修复**：`WubiLibrary.StripBrackets` 剥离全角/半角括号内容

3. **生僻字根会被读错，与括号无关**
   - `戋` → 读成「巾」（jīn）；`纟` → 读成「减/角」；`礻` → 读成「十」；`疒` → 「病」；`彡` → 「三」
   - **修复**：`WubiLibrary.SpeechOverrides` 同音字替换表，**只影响朗读、不影响界面显示文字**
   - 注意：`GetSpeakText(WubiRootInfo)` 里**键名也要过覆盖表**，否则 X 键键名「纟」仍会读错

4. 后鼻韵母 `eng` 无自然成音节的常用字，用「鞥」承载；`ong` 不能自成音节，用「轰」承载

> 方法学：ASR 反听是检验 TTS 发音质量的有效手段。**合成后回读一遍**，能发现肉眼看代码发现不了的问题；本次三个设计缺陷全部由它暴露。

### 已知限制
- 单条超长朗读（如 25 条口诀连读约 63 秒）超出 ASR 单次识别上限，仅影响"用 ASR 抽验"这一步，不影响软件本身播放
- 个别字根字读音仍可能不理想（TTS 层面限制）；已修掉 ASR 实测确认读错的 5 个字
- 本环境无显示终端，界面交互需真机确认
