## TypeMaster 第二轮改造（6 项）

1. **架构重构：删除 `GlassWindow` 基类，改走附加属性**
   - 根因：第一轮把 XAML 根部改成 `<app:GlassWindow>` 而代码后置仍是 `: Window`，XAML 分部类与 C# 分部类基类不一致，VS 报「"MainWindow"的分部声明一定不能指定不同的基类」，并连锁报出 `DataContext`/`Close`/`RootBorder`/`Width`/`Height`/`Left`/`Top` 不存在、`WindowState` 被当变量、`NicknameWindow` 无 `Owner`/`ShowDialog` 等共 30 条错误（均为派生失败的连锁反应）。
   - 方案：删除 `src/TypeMaster.App/GlassWindow.cs`，新增 `GlassWindowBehavior.cs`（附加属性 `Enable` + `TryDragMove`）。四个窗体 XAML 根部恢复标准 `<Window>`，代码后置恢复 `: Window`，通过 `glass:GlassWindowBehavior.Enable="True"` 启用玻璃。**架构上使基类不一致不可能再发生。**
   - 教训：给 WPF 窗体加通用行为，**优先附加属性，不要继承自定义基类**。

2. **难度滑动条折叠**
   - `TypingPage` / `GamePlayPage` 在难度按钮后加 `ToggleButton DifficultyExpander`（ChevronDown/ChevronUp 图标随 `IsChecked` 切换），滑动条 Border 用 `BooleanToVisibilityConverter` 绑定 `IsChecked`，默认收起。

3. **首页可读性**
   - `GlassTextBrush` `#F2142029`（近纯黑）、`GlassTextSecondaryBrush` `#EE42576B`（加深蓝灰），`ThemeManager.ApplyGlassPalette` 同步亮/护眼绿/暗黑三套。
   - 欢迎横幅改深蓝实色（Opacity 0.95，三段渐变 `#F20D47A1`→`#F21565C0`→`#F21976D2`），"欢迎使用"24 号字 + `DropShadowEffect`。

4. **游戏难度大幅下调**（面向三四年级）
   - 生命 4~6 → **6~8**；刷怪间隔 1100~3200ms → **1900~4600ms**；同屏 2~6 → **1~4**；速度 24~110px/s → **14~33px/s**。
   - 新增 `MaxWordLength`：1级≤4 字符，2-3级≤5，4-5级≤6，6-7级≤8，8-9级≤10，10级不限。
   - 微调系数收窄：`spawn*(1-0.14*tune)` / `speed*(1+0.20*tune)` / `mole*(1-0.12*tune)`。

5. **卡通动画 + 音效**
   - `GamePlayPage.xaml` 共 **42 条** `Storyboard.TargetProperty` 动画：太空大战小飞船（巡航+轻浮+尾焰）、打地鼠吉祥物（探头+摇摆）、抓小偷楼房窗户闪灯+警察叔叔奔跑颠动、青蛙吃虫池塘双涟漪+青蛙呼吸缩放+眨眼（`DiscreteDoubleKeyFrame` 0/2.6/2.75s）。
   - 音效：`ISoundService` 扩至 **12 个**方法（`PlayShoot/PlayHit/PlayMiss/PlayCombo/PlayStart/PlayGameOver/PlayPop/PlayEat/PlayCatch` 等），`SoundService` 用 `readonly record struct Tone(Frequency, Duration, Gap)` + `Console.Beep` 在 `Task.Run` 后台线程播放，**无需外部音频文件**。
   - 注意：MDIX 4.9.0 **没有 `Frog` 图标**，青蛙用 `Ellipse`/`Rectangle` 手绘。

6. **自动小版本号**
   - `TypeMaster.App.csproj` 加 `VersionBuild=$([System.DateTime]::Now.ToString('MMdd'))`、`VersionRevision=$([System.DateTime]::Now.ToString('HHmm'))`，实测生成 `1.0.0828.2213` → 下次构建 `1.0.0828.2214`（每次构建自动递增）。
   - `TypeMaster.Core/AppVersion.cs` 提供 `Current`/`Display`/`DisplayWithLabel`；设置页"关于"区绑定 `{Binding AppVersionText}`。

### 关键踩坑
- **静态类名不要与 ViewModel 属性同名**：`DifficultyLevel` 静态类与 VM 属性 `DifficultyLevel` 冲突，C# 优先解析实例属性，导致 CS0236 + 一串 CS7036/CS1061。改名为 `DifficultyScale` 解决。
- **MVVMTK0034**：`OnXxxChanged` 里不要直接读写 `_xxx` 字段，用局部 `var v = Clamp(value)`。
- **`HwndSource.AddHook` lambda 的 `handled` 参数必须写 `ref bool`**，否则 CS1676。
- `Card` 玻璃化隐式样式放 `App.xaml` 的 Application 自身资源字典，`BasedOn` 才能稳定解析到 MDIX 默认样式；放 `GlassStyles.xaml` 会解析不稳。
