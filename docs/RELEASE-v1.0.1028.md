TypeMaster v1.0.1028
发布日期：2026-10-28 ｜ 构建版本：1.0.1028.1343 ｜ Windows 10 / 11（64 位）

✨ 更新亮点
- 中文打字新增拼音标注：每个汉字上方显示拼音、下方显示汉字，逐字对齐；内置 20910 字拼音表，多音字按语料实测校正（如「地 de」「长 cháng」「教 jiāo」），默认开启，可在设置页关闭
- 打对即拼读：打对某个汉字时自动朗读该字的标准读音——读汉字而非拼音串，避免语音引擎把「lěi」这类音节按英文念错；可在设置页关闭
- 拼音声母/韵母双色：正在输入的汉字，拼音声母显示为橙色、韵母为蓝色（如「春 chūn」= 橙 ch + 蓝 ūn），音节结构一眼可见；打对的字整体绿、打错的字整体红
- 语音朗读大幅自然化：TTS 升级为双引擎，优先使用 WinRT 语音合成，告别 Win7 时代老语音的机械音；自动挑选最合适的中文语音，新朗读自动打断旧朗读
- 修复 BGM 丢失：从首页切回游戏乐园后，背景音乐不再消失
- 修复高分屏虚拟键盘：高分屏全屏后，部分界面虚拟键盘未按分辨率适配的问题已修复

📦 安装与升级
- 下载附件 TypeMaster-v1.0.1028-win-x64.zip
- 解压到任意目录（免安装，无需 .NET 运行时）
- 双击 TypeMaster.exe 运行
- 从旧版升级：直接覆盖旧 exe 即可，使用者数据、成绩、闯关进度全部保留

⚠️ 说明
- 仅支持 Windows；包体约 200 MB（自包含单文件，内含 .NET 运行时与原生库；较上一版增大约 24 MB，为接入 WinRT 语音引擎所需的系统组件）
- 多音字取该字在语料中的最常用读音（暂无语境消歧），个别语境下可能与实际读法不同
- 拼音辅助默认开启；设置页 → 拼音辅助，可分别控制「显示拼音」与「打字拼读」
- 朗读功能需系统已安装中文语音引擎，未安装时自动跳过；想要真人级音色，可在 Windows「设置 → 辅助功能 → 讲述人 → 添加自然语音」免费安装（离线可用），应用会自动优先选用
