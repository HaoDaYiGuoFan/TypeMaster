# TypeMaster v1.0.928 发行说明

> **发布日期**：2026-09-28
> **构建版本**：`1.0.0928.1426`
> **适用平台**：Windows 10 / 11（64 位）

本轮修复了两个用户反馈的实际问题：**打字练习打完一行就停住**、**游戏单词反复重复**。

---

## ✨ 重点更新

### 1. 打字练习可以一直打下去了

**问题**：打完第一行后不再出现后续内容，只能停在一行。

**原因**（三层叠加，均已修复）：

| # | 原因 | 说明 |
| --- | --- | --- |
| 1 | 目标文本过短 | 等级 1 的目标长度只有 40 字符，恰好约一行 |
| 2 | 续接时重复同一篇 | 长度不足时会把同一篇文章再拼一遍，产出肉眼可见的重复 |
| 3 | 视口不跟随输入 | 对照区高度有限，不滚动就看不到后面的内容 |

**修复**：

- ✅ **10 级目标文本长度整体加长约一倍**
  （等级 1：40 → 80 字符；等级 10：600 → 950 字符）
- ✅ **长度不足时拼接不同文章**，不再重复同一篇
- ✅ **新增自动续接**——打到接近末尾时自动追加一段**新的**随机内容，
  练习可以一直进行；想停下来点「提交成绩」即可
- ✅ **对照区自动滚动**——当前输入字符始终可见
- ✅ 对照区最大高度 180px → 260px，一屏可见更多行

> **说明**：课程关卡、指定文章、五笔模式下**不会**自动续接，
> 以保证考核公平并尊重你选定的练习内容。

### 2. 游戏单词不再反复重复

**问题**：每款游戏翻来覆去就那几个单词。

**原因**：旧词库仅有 **66 个词**（简单 24 / 普通 22 / 困难 20）。
实测连抽 20 次只有 **14 个不同词**。

**修复**：词库扩充到 **4700 词**（约 71 倍）

| 难度档 | 字母数 | 词量 |
| --- | --- | --- |
| 简单 | 3-5 | **1500 词** |
| 普通 | 6-8 | **2000 词** |
| 困难 | 9+ | **1200 词** |

词库基于 google-10000-english 词频表整理，并做了必要过滤：

- 剔除 1-2 字母词（游戏是"锁定首字母后逐字匹配"，`a`/`an`/`it` 无练习价值）
- 剔除缩写、技术网络词、品牌机构名、地名人名日期
- 剔除敏感词与消极词汇
- 剔除含长辅音簇、元音占比过低的非自然词
- 每档只保留**词频最高**的若干个，避免长尾生僻词影响体验

## 📦 安装与使用

1. 下载下方附件 `TypeMaster-v1.0.928-win-x64.zip`
2. 解压到任意目录（无需安装）
3. 双击 `TypeMaster.exe` 运行

**无需预先安装 .NET 运行时**——发布包为自包含单文件，
原生库已一并打包，单独拷贝 exe 到其他目录也能运行。

### 系统要求

- Windows 10 / 11（64 位）
- 语音朗读功能需系统已安装中文语音引擎
  （「设置 → 时间和语言 → 语音」中可添加；未安装时朗读会自动跳过，不影响其他功能）

### 数据位置

用户数据存放于 `%LOCALAPPDATA%\TypeMaster\`：

```
typemaster.db            # 打字成绩
user_profile.json        # 昵称与等级
custom_articles.json     # 自定义文章
course_progress.json     # 闯关进度
```

**从旧版本升级不会丢失数据**：数据库采用非破坏性升级
（检查列是否存在，缺失才 `ALTER TABLE ADD COLUMN`），历史成绩与设置完整保留。

**备份方式**：直接复制整个 `%LOCALAPPDATA%\TypeMaster` 目录。

## ⚠️ 已知限制

- **仅支持 Windows**——项目使用 WPF 与 Windows 专有音频/语音 API
- **发布包较大（175 MB）**——因为是自包含单文件，内含 .NET 运行时与原生库；
  好处是目标机器无需安装任何运行时
- **词库仍含极少数不理想词**（如 `bikini`、`eminem`）。
  这些是真实英文单词，不影响练打字；如遇到明显不合适的词，欢迎提 Issue
- **成绩不跨设备同步**——数据存于本地，换机需手动复制
